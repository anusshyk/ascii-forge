# ascii-forge

Procedurally generated ASCII animations streamed over `curl`, in the spirit of
[ascii.live](https://github.com/hugomd/ascii-live). Instead of hand-made frame
files, every animation is **generated by code in real time**, with live controls.
Zero dependencies, Node 18+.

Inspired by [ascii.live](https://github.com/hugomd/ascii-live) by hugomd. This project shares no code with it.

## Run

    node server.js            # http://localhost:8080  (PORT=3000 node server.js to change)

## Watch

    curl localhost:8080/donut
    curl "localhost:8080/fire?color=ice&fps=30"
    curl "localhost:8080/clock?w=100&h=30"

| Animation | What it is |
|-----------|------------|
| donut     | spinning 3D torus with z-buffer shading |
| plasma    | demoscene plasma |
| matrix    | falling glyph rain |
| starfield | warp-speed star flight |
| fire      | heat-diffusion flames |
| life      | Conway's Game of Life (auto-reseeds) |
| waves     | layered ocean |
| clock     | live clock with seconds bar |
| tunnel    | checkered tunnel flythrough |
| propose   | she asks, he says yes (hearts and confetti) |

## Options (query string)

`fps` (1-60), `w` / `h` (size), `color` (fire, matrix, ice, rainbow, mono),
`speed` (0.1-5), `duration` (seconds, then the stream ends).

## Add your own animation

In `animations.js`, add a function `(t, w, h, state) => ({ chars, vals })`
where `chars` is an array of `w*h` characters and `vals` is `w*h` numbers in
0..1 used for color. Export it, add a line to `meta`, done.
